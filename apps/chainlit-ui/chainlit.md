# ผู้ช่วยดูแลโครงข่าย IP-MPLS

ระบบนี้ตอบคำถามเกี่ยวกับโครงข่าย IP-MPLS โดยดึงข้อมูลจริงจาก 3 ระบบ

| ระบบ | ข้อมูล |
|---|---|
| PostgreSQL | ticket, การตั้งค่าอุปกรณ์, วงจรลูกค้า |
| Neo4j | โครงสร้างการเชื่อมต่อและ adjacency |
| OpenSearch | log อุปกรณ์ และเอกสารปฏิบัติการ |

## สิ่งที่จะเห็นระหว่างที่ระบบทำงาน

1. **ตรวจสอบขอบเขตคำถาม** — ถ้าคำถามอยู่นอกขอบเขต ระบบจะไม่แตะฐานข้อมูลเลย
2. **แผนการทำงาน** — ระบบคิดเองว่าต้องดึงข้อมูลจากไหนก่อนหลัง แสดงเป็นแผนภาพ
3. **การเรียกเครื่องมือทีละขั้น** — กดเปิดดูข้อมูลดิบที่ได้จากแต่ละระบบได้
4. **คำตอบพร้อมแหล่งอ้างอิง** — ทุกข้อสรุปบอกว่ามาจากระบบไหน
5. **มาตรวัดต้นทุน** — จำนวน token, ความเร็ว และขนาด context ที่ใช้จริง

## ขอบเขต

- ครอบคลุมพื้นที่ **BKK** และ **NBI** เท่านั้น รวม 10 อุปกรณ์
- ข้อมูล log ย้อนหลัง 30 วัน · ticket ย้อนหลัง 90 วัน
- ไม่มี real-time metric มีเฉพาะ log, ticket และ config

ถ้าถามถึงอุปกรณ์หรือพื้นที่ที่ไม่มีในระบบ ระบบจะตอบว่าไม่พบ **ไม่เดาคำตอบให้**
