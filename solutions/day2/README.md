## Lab 2 — จุดตัดสินใจที่สำคัญ

### 4 ประเภท ไม่ใช่ 2

```
in_scope · general_knowledge · needs_clarification · out_of_scope
```

การมองว่าเป็นคำถาม ใช่/ไม่ใช่ เป็นความผิดพลาดที่พบบ่อยที่สุด
*"router คืออะไร"* ไม่ควรถูกปฏิเสธ และไม่ควรไปค้นฐานข้อมูล

### fast path ต้องไม่มั่นใจเกินไป

```python
if off_hits and not domain_hits:      # ต้องมี and not domain_hits
```

*"ส่งรายงาน log ให้ทีมก่อนไปกินข้าว"* มีทั้งคำในโดเมนและนอกโดเมน — gate ที่ปฏิเสธเพราะคำว่า "กินข้าว" แย่กว่าไม่มี gate เลย

### regex ภาษาไทยใช้ `$` และ `\b` ไม่ได้

```python
# ผิด - ไทยไม่จบประโยคด้วยคำเดียว
re.compile(r"^(ดูให้หน่อย|ปกติไหม)\s*$")

# ถูก - match แค่ส่วนต้น
re.compile(r"^\s*(ดูให้|เช็คให้|ตรวจให้|ช่วยดู)")
```

และ `\b` ไม่ทำงานกลางประโยคภาษาไทย เพราะอักขระไทยทุกตัวเป็น word character และไม่มีช่องว่างคั่น

*(บั๊กสองข้อนี้ถูกพบจากการเขียน test — เป็นตัวอย่างว่าทำไม `tests/test_intent_gate.py` ถึงมีค่า)*

### คำถามนอกขอบเขต ≠ การเปลี่ยนเรื่อง

จุดที่คนพลาดมากที่สุด ผู้ใช้ที่แทรกคำถามเล่นๆ กลางการสืบสวน **ไม่ได้เปลี่ยนหัวข้องาน** การล้าง context ตรงนั้นคือการทำร้ายผู้ใช้

แก้ด้วยลำดับ: **Intent มาก่อน Memory เสมอ** และ `out_of_scope` ต้อง return ก่อนถึงโค้ดตรวจ topic shift

### ต่างจาก `apps/agent-api/` อย่างไร

| | Workshop 2 (ไฟล์นี้) | Day 3 (`apps/`) |
|---|---|---|
| เรียก tool | ฟังก์ชัน Python ตรงๆ | ผ่าน MCP |
| ใช้ได้กับ Claude Desktop | ไม่ได้ | **ได้** |
| ขนาด | ~450 บรรทัดไฟล์เดียว | หลายโมดูล |
| วงจรการทำงาน | **เหมือนกันทุกประการ** | เหมือนกัน |

**บทเรียน**: การเปลี่ยนไปใช้ MCP ในวันที่ 3 ไม่ได้แก้ตรรกะของ loop เลย แก้แค่ชั้นที่เรียก tool — เพราะ loop คือส่วนที่ต้องเข้าใจ ส่วน MCP คือชั้นเชื่อมต่อ

### 3 ส่วนที่ควรอ่าน

**`LoopGuard`** — สามเงื่อนไขหยุดที่แยกจากกัน แต่ละข้อเอาชนะได้ทีละข้อ รวมกันจึงกันได้ทุกรูปแบบ loop ที่พบจริง

**`resolve()`** — รูปแบบ `step.1.tickets.*.device_id` คือสิ่งที่ทำให้ผลของขั้นก่อนกลายเป็น argument ของขั้นถัดไปได้อัตโนมัติ ถ้าไม่มี โมเดลต้องคัดลอกค่าเอง ซึ่งทำพลาดบ่อย

**`execute()`** — ขั้นที่ไม่ขึ้นต่อกันรันขนานด้วย `asyncio.gather` และใช้ `asyncio.to_thread` เพราะ tool เป็น sync ถ้าเรียกตรงๆ จะบล็อก event loop แล้วไม่เกิดการขนานจริง
